03

採用案 — コンセプトとフック

借金を抱えた宿屋の女主人が、30日以内に返済する経営ローグライト。1周＝ゲーム内30日＝実時間30〜60分。

フックは「借金の締切」。棚で一行で伝わり、プレイ中は常に緊張が持続する。毎周ランダムな客・イベント・スキルが配られ、失敗しても返済額に応じてエンディングが分岐する。つまり失敗そのものがコンテンツになる——これが低予算でボリューム感を出す中核の仕掛けである。

コアループ

朝仕入れと準備限られた資金で食材・寝具・設備を選ぶ。何を切り捨てるかの判断。
昼客の受け入れランダムな客が訪れる。支払い能力・要求・トラブルの種はそれぞれ異なる。
夜イベント処理盗難、病、上客の紹介。選択がその周の展開を変える。
清算返済と改装利益を返済に回すか、宿に再投資するか。30日後に結末が決まる。

収集要素（リプレイ動機）

  • 客図鑑 — 一度泊めた客が記録される。条件付きでしか現れない客がいる
  • 結末図鑑 — 返済額と選択で分岐する複数エンディング。失敗ルートも収集対象
  • 設備ツリー — 周を跨いで解放される改装オプション
04

なぜ20万円で成立するのか

この企画の本質は物語ではなくアート量の設計にある。コンテンツを足してもアート費が増えない構造を先に作った。

アート資産の増幅設計
要素発注量画面上の見え方増幅率
背景1 枚改装3段階＋昼夜差分で使い回す×4
キャラクター立ち絵4 体表情差分5種で20カット相当×5
泊まり客0 体（内製）アイコン／シルエットで処理追加費 0
UI・アイコン素材購入画面の大半を占める主役—
構造上の利点

舞台が宿屋の1画面のみで、画面がUI主体であるため、イベントや客を追加してもアート発注が発生しない。コンテンツ量とコストが連動しないことが、この予算規模で唯一勝てる形である。

09

段階投資プラン

プロデューサーレビューでの指摘——「全年齢の最頻値が0本と自ら調査しておいて、1000本の根拠は何か」——への回答がこの節である。

フェーズ1 — 全年齢版でリリース

200,000円 / 6ヶ月

本企画書の範囲。損益分岐は200本、目標1000本は分岐点の5倍。ここで投じる資金の上限が20万円に確定する。仮に完全に外しても損失はこの額を超えない。

フェーズ2 — 収益を再投資して拡張

フェーズ1の売上から充当

調査で確認された「アダルトは全年齢の10倍以上」という市場差に対し、追加SKUとして展開する。自己資金ではなく売上から投資するため、フェーズ1が不発なら実行しないという判断が自動的に成立する。

プロデューサー承認理由

下振れが20万円で確定し、上振れは自己資金ではなく売上から取りに行ける。リスクの上限が閉じている点をもって承認する。
