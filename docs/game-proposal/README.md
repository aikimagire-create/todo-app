# 『負債の宿屋』企画書

DLsite向け同人ゲームの企画案。プロデューサー / ディレクター / プランナーの3ロールによる企画会議の成果物。

- **プレゼン資料（HTML）**: [`fusai-no-yadoya.html`](./fusai-no-yadoya.html)

## 採用基準

| 基準 | 目標 | 本企画の回答 |
| --- | --- | --- |
| 予算 | 20万円以内 | 200,000円（内訳確定・予備費35,000円込み） |
| 開発工数 | 半年 | 6ヶ月（M3で仕様凍結） |
| 販売本数 | DLsiteで1000本超 | 損益分岐200本 / 目標1000本 = 分岐点の5倍 |

## 企画概要

借金を抱えた宿屋の女主人が、**30日以内に返済する**経営ローグライト。
1周＝ゲーム内30日＝実時間30〜60分。

毎周ランダムな客・イベント・スキルが配られ、失敗しても返済額に応じてエンディングが分岐する。
**失敗そのものがコンテンツになる**構造で、低予算のままボリューム感を出す。

## 市場調査の要点（プランナー）

| 調査項目 | 数値・事実 |
| --- | --- |
| 全年齢ゲームの販売数**最頻値** | 0本（一本も売れない作品が最多） |
| 販売数の分布 | 指数型ロングテール |
| アダルト / 全年齢の販売差 | アダルトが10倍以上 |
| 年間上位作の価格 | 平均 2,640円 / 中央値 2,420円 |
| 上位ランキングの構成 | ゲームが約75% |
| 発売1週目の比重 | 総売上の約20%（初週×5で着地予測） |
| 売上ピーク時期 | 8月・12月（大型セール連動） |
| ランキング入りの助走 | 約120日 |
| 立ち絵の外注相場 | 1体 10,000〜50,000円 |

**導かれる結論**: 立ち絵1体3万円なら6体で予算が消える。予算20万円では「コンテンツ量で殴るゲーム」は
構造的に作れず、**システムでリプレイ性を生む設計**以外に選択肢はない。

## 3案の比較とディレクター判定（第1ラウンド）

| 案 | ジャンル | 判定 | 理由 |
| --- | --- | --- | --- |
| C案 迷宮図書館アーカイヴ | 探索RPG | 工数で不成立 | マップ・敵・イベント・バランス調整で工数が爆発 |
| B案 デッキ・オブ・ザ・ダムド | デッキ構築 | 差別化で不成立 | 大型タイトルと直接比較され、システム単体では刺さらない |
| A案 ギルド酒場の錬金術師 | 経営シム | 条件付き差し戻し | 低アート量の構造は正しいがフックが不足 |

差し戻し条件を満たす形にA案を再設計したものが『負債の宿屋』であり、第2ラウンドで**採用**。

## なぜ20万円で成立するのか（アート量の設計）

| 要素 | 発注量 | 画面上の見え方 | 増幅率 |
| --- | --- | --- | --- |
| 背景 | 1枚 | 改装3段階＋昼夜差分で使い回す | ×4 |
| キャラクター立ち絵 | 4体 | 表情差分5種で20カット相当 | ×5 |
| 泊まり客 | 0体（内製） | アイコン／シルエットで処理 | 追加費 0 |

舞台が宿屋の1画面のみで画面がUI主体のため、イベントや客を追加してもアート発注が発生しない。
**コンテンツ量とコストが連動しない**ことが、この予算規模で勝てる唯一の形。

## 開発スケジュール（6ヶ月）

| 月 | マイルストーン | 完了判定 |
| --- | --- | --- |
| M1 | コアループのプロトタイプ | 仮素材で1周30分が通しで回る |
| M2 | システム実装 | 客・イベント・スキル・図鑑が動作 |
| M3 | コンテンツ量産／アート発注確定 | 外注へ発注完了・**仕様凍結** |
| M4 | アート統合／Ci-en 開発日誌開始 | 本素材差し替え・露出開始 |
| M5 | 体験版公開 | フィードバック収集とバランス調整 |
| M6 | 磨き込み・ストアページ整備 | 8月リリース |

リリースを8月に固定する理由: 8月は売上ピークであり、かつランキング入りに必要な約120日の助走を経て
年末セールで二度目の山を取れる。

## 販売計画と損益分岐

価格 **1,540円**（発売2週間は20%OFF＝1,232円）。手取り単価は保守的に1,000円で計算。

| シナリオ | 販売本数 | 概算手取り | 対 投資 |
| --- | ---: | ---: | ---: |
| 損益分岐点 | 200 | 200,000 | 1.0× |
| 下振れ | 400 | 400,000 | 2.0× |
| **目標** | **1,000** | **1,000,000** | **5.0×** |
| 上振れ | 2,500 | 2,500,000 | 12.5× |

> DLsiteの還元率は価格連動の階段式（低単価ほど手数料が高く、高単価帯で創作者側の取り分が増える）。
> 上表は保守側に寄せた概算であり、**実際の料率は契約時に要確認**。

## 段階投資プラン

プロデューサー指摘「全年齢の最頻値が0本と自ら調査しておいて、1000本の根拠は何か」への回答。

- **フェーズ1**（200,000円 / 6ヶ月）— 全年齢版でリリース。**投じる資金の上限が20万円に確定**する。
- **フェーズ2**（フェーズ1の売上から充当）— 市場差（アダルトは全年齢の10倍以上）に対し追加SKUを展開。
  自己資金ではなく売上から投資するため、フェーズ1が不発なら実行しない判断が自動的に成立する。

**承認理由**: 下振れが20万円で確定し、上振れは売上から取りに行ける。リスクの上限が閉じている。
